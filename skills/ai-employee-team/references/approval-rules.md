# 全操作の承認ルール

全社員が従う最優先ルール。**外部に変化を起こす操作はすべて事前確認する。**
情報の検索・閲覧は全範囲を対象に自動実行してよい。

## 権限一覧

| 操作 | 扱い |
|------|------|
| Google Drive 検索・閲覧 | 自動実行可 |
| Slack 検索・閲覧 | 自動実行可 |
| Gmail 検索・閲覧 | 自動実行可 |
| Web 調査 | 自動実行可 |
| カレンダーの閲覧（予定確認・空き検索） | 自動実行可 |
| この画面内に下書きを表示 | 自動実行可 |
| 要約・分析 | 自動実行可 |
| Googleドキュメント 新規作成 | **事前確認** |
| Wordファイル 新規作成 | **事前確認** |
| 既存資料の編集・上書き | **事前確認** |
| カレンダー予定の作成・変更・キャンセル | **事前確認** |
| Slackへの投稿・返信 | **事前確認（送信直前に再確認）** |
| Gmailの送信・返信 | **事前確認（送信直前に再確認）** |
| Gmail上の下書き保存 | **事前確認**（下書き保存も「作成」に当たる） |
| ファイル共有範囲の変更 | **事前確認** |
| 削除 | **毎回、個別に強い再確認** |

## 確認の型

変化を起こす操作の前に、必ず次の3点を提示してから承認を求める。

1. **何をするか**（例：Googleドキュメントを新規作成／Slackの #general に返信／予定を1件追加）
2. **対象・宛先・共有範囲**（作成先フォルダ、宛先・CC、投稿チャンネル、参加者など）
3. **中身**（本文案・資料の下書き・予定の詳細）

例：
> 資料の下書きとオーディンの監査が完了しました。
> 以下の内容で **Googleドキュメントを新規作成** してよいですか？
> ・作成先：マイドライブ ＞ AI作成資料
> ・タイトル：〇〇に関する協議
> ・本文：（下書きを表示）

「作成して」「送って」と承認された後だけ実行する。

## 特に強い確認が必要なもの

- **削除**：取り消せないため、対象を1件ずつ列挙し「本当に削除してよいか」を個別に再確認する。
- **`@channel` / `@here` / 大人数メンション**：影響範囲が大きいので目立つ形で警告してから確認する。
- **全員に返信（Reply All）**：宛先全員を明示してから確認する。
- **共有範囲の変更**（社外公開・リンク共有化など）：誰に見えるようになるかを明示する。

## 「送って」と最初から頼まれた場合

最初から「送っておいて」と言われても、いきなり送らない。
**必ず一度、完成した文面と宛先を表示し、再確認を取ってから**送信する。
