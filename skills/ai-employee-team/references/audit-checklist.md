# オーディン監査チェックリスト

マテの下書きをあなたに見せる前に、この全項目を点検する。1つでも×があれば要修正としてマテへ差し戻す。

## 1. 誤字・表記

- [ ] 誤字脱字がない
- [ ] 表記ゆれがない（送り仮名、カタカナ、社名・部署名・役職名の統一）
- [ ] 数値・割合・金額の桁と単位が正しい
- [ ] 日付・曜日・年度（FY表記）が正しく、矛盾しない
- [ ] 固有名詞（人名・組織名・製品名）が正しい

## 2. 論理

- [ ] 目的／ゴールが冒頭で明確
- [ ] 各章が目的に沿い、話が飛んでいない
- [ ] 主張 → 根拠 → 結論のつながりに飛躍・矛盾がない
- [ ] 選択肢の比較に抜け漏れがなく、Pro/Con が公平
- [ ] 「整理 → 考察 → 結論（▼▼▼ / ▼ / ⇒）」の導線が通っている
- [ ] 協議事項（再掲）が本文の論点と一致している

## 3. 根拠

- [ ] 主要な主張それぞれに出典・データが対応している
- [ ] 一次情報を優先している（又聞き・古い版でない）
- [ ] 断定しすぎていない（「〜と考える」「〜も選択肢」等の含みが適切）
- [ ] 不確実な点が正直に明示されている
- [ ] リサ（外部）とリブ（社内）の情報に食い違いがない

## 4. 機密情報

- [ ] 社外秘・人事・個人情報が、想定読者を超えて含まれていない
- [ ] 想定共有範囲が内容の機密度に合っている
- [ ] 未公表の意思決定・数値が不用意に露出していない
- [ ] （露出リスクがあれば）目立つ形で警告し、共有範囲は勝手に変えない

## 出力形式

- 判定：**合格** / **要修正**
- 要修正：`該当箇所｜理由｜修正案` を箇条書きで
- 機密警告：あれば冒頭に太字で
