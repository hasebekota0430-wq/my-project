# 資料作成テンプレート（マテ用）

添付された2件の資料（「役員情報共有会・グローバルスキル議論資料」「大崎さんの配置に関する協議」）から
抽出した、事務局スタイルの**協議・議論ペーパー**の型。マテはこの型・見た目・構造を基本的に踏襲する。

## 体裁（見た目）

| 要素 | 目安 | 見た目 |
|------|------|--------|
| 日付・部署（表紙） | 15pt / グレー(#666666) | タイトルの上に「2026年7月7日」「人事本部（事務局）」等 |
| タイトル | 26pt | 中央または左、資料名を大きく |
| 大見出し `1.` | 20pt・太字 | 薄いグレーの帯（背景 #D9D9D9）で章を区切る |
| 小見出し `1-1.` | 16pt・太字 | 帯なし。「ゴール」等の名前付きでも可 |
| 本文 | 10〜11pt | 結論先出し・簡潔 |
| 箇条書き | ・ | 具体・根拠は一段下げて入れ子に |
| 表見出しセル | 11pt / グレー(#666666) | 比較・一覧は表で見せる |
| 考察記号 | ▼▼▼ / ▼ / ⇒ | 「整理 → 考察 → 結論」の導線 |

- 日本語フォントはゴシック体（Noto Sans JP／Arial Unicode MS 相当）。
- 章番号は `1.` `2.`、小見出しは `1-1.` `2-1.` の形。

## 標準構成（骨子）

案件に応じて取捨選択するが、基本は次の流れ。

```
[日付]
[部署（事務局）]
[タイトル]

1. 本日の目的／ゴール
   1-1. 目的        … 何のための場か（多くは「認識をそろえる」目的で、決定・選定の場ではないと明示）
   ゴール           … 箇条書きで到達点
   本日の協議事項サマリ … これから議論する点を先に列挙

2. 背景・全体像
   … なぜ議論するのか。経緯・現状・全体像。過去の意見や位置づけを表や引用で。

3. 論点／選択肢
   3-1. 選択肢の整理  … A/B/C などのパターン。比較表（内容・Pro・Con・推奨度）
   3-2. 時期・条件など … 必要なら別表
   3-3. 事務局の整理  … 結論の方向性（断定しすぎず「〜が合理的と考える」）

4. 本日の協議事項（再掲）
   … # / 協議・確認事項 / 意図・視点 の3列の表

5. 今後の進め方（ネクスト）／Appendix
   … 決定後の段取り、スケジュール、継続検討事項
```

## トーンの決まり

- 読者は役員・執行責任者。丁寧・簡潔・中立。
- 「意思決定や選定の場ではなく、認識をそろえる場」と目的を明示することが多い。
- 事務局の結論は方向性として示し、断定を避ける（「〜と考える」「〜も十分に選択肢」）。
- 記号 `▼▼▼`（大きな結論への導線）、`▼`（結論）、`⇒`（展開）で流れを可視化。

## 出力（下書き表示）

マテはまずこの型で**この画面上に**下書きを出す。見出し・箇条書き・表・考察記号まで再現する。
実ファイル（Google Docs／Word）化は、監査と承認の後だけ行う。
埋めるだけの雛形が必要なときは `templates/discussion-paper-template.md` を複製して使う。
